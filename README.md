# Syntax Tree Maker

An intuitive linguistic syntax tree editor for the browser.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Interactions

- **Double-click** the canvas to add a node
- **Drag** the orange handle under a selected node to connect or spawn a child
- **Click a branch** to insert an intermediate node
- **Shift-click** or drag a marquee to multi-select, then **Make parent**
- **Enter** adds a child · **Tab** adds a sibling · **P** makes a parent
- **Look** panel for themes, fonts, size, and branch style
- Export **SVG** or **PNG**; trees autosave in local storage
